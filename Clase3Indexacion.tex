\section{Indexación de vectores}\label{indexaciuxf3n-de-vectores}

\begin{frame}{¿Qué aprenderemos?}
\phantomsection\label{quuxe9-aprenderemos}
Al finalizar esta sesión, el estudiante será capaz de:

\begin{itemize}
\tightlist
\item
  \textbf{Comprender la estructura posicional} de los vectores en R y la
  regla fundamental del índice inicial (índice 1).
\item
  \textbf{Extraer elementos específicos} (individuales o múltiples)
  utilizando vectores de índices positivos.
\item
  \textbf{Excluir datos no deseados} o atípicos de un vector de forma
  segura mediante el uso de índices negativos.
\item
  \textbf{Consultar información por etiqueta} utilizando la indexación
  en vectores nombrados.
\item
  \textbf{Editar y sobrescribir} valores dentro de un vector sin
  necesidad de reescribirlo por completo.
\item
  \textbf{Aplicar la indexación posicional} como herramienta de primer
  nivel para la limpieza y corrección de datos estadísticos.
\end{itemize}
\end{frame}

\section{Introducción: ¿Qué es un índice en
R?}\label{introducciuxf3n-quuxe9-es-un-uxedndice-en-r}

\begin{frame}{Introducción: ¿Qué es un índice en R?}
En R, un vector es una estructura de datos unidimensional que almacena
elementos del mismo tipo. Para poder interactuar con estos elementos
(leerlos, modificarlos o eliminarlos), R asigna automáticamente a cada
posición un número entero llamado \textbf{índice}.
\end{frame}

\begin{frame}[fragile]{}
\phantomsection\label{section}
\begin{tcolorbox}[enhanced jigsaw, leftrule=.75mm, left=2mm, colback=white, toptitle=1mm, bottomrule=.15mm, arc=.35mm, breakable, title=\textcolor{quarto-callout-important-color}{\faExclamation}\hspace{0.5em}{Importante}, coltitle=black, colbacktitle=quarto-callout-important-color!10!white, bottomtitle=1mm, opacityback=0, rightrule=.15mm, toprule=.15mm, colframe=quarto-callout-important-color-frame, opacitybacktitle=0.6, titlerule=0mm]

\textbf{Nota fundamental:} A diferencia de otros lenguajes de
programación como Python o C (donde el primer elemento tiene el índice
0), \textbf{en R la indexación comienza estrictamente en 1}. El primer
elemento de un vector está en la posición 1, el segundo en la 2, y el
último en la posición \texttt{length(vector)}.

\end{tcolorbox}
\end{frame}

\begin{frame}[fragile]{Acceso a elementos}
\phantomsection\label{acceso-a-elementos}
Para acceder a los elementos de un vectos mediante su índice, utilizamos
los corchetes \texttt{{[}\ {]}}.
\end{frame}

\section{Tipos de Indexación}\label{tipos-de-indexaciuxf3n}

\begin{frame}[fragile]{Indexación posicional}
\phantomsection\label{indexaciuxf3n-posicional}
Para ilustrar los conceptos, supongamos que estamos procesando datos de
un muestreo biométrico en un laboratorio, específicamente el peso en
gramos de una muestra de cachamas.

\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\# Vector de pesos observados}
\NormalTok{pesos\_cachama }\OtherTok{\textless{}{-}} \FunctionTok{c}\NormalTok{(}\FloatTok{450.2}\NormalTok{, }\FloatTok{465.1}\NormalTok{, }\FloatTok{440.8}\NormalTok{, }\FloatTok{480.5}\NormalTok{, }\FloatTok{455.0}\NormalTok{, }\FloatTok{470.3}\NormalTok{)}
\end{Highlighting}
\end{Shaded}
\end{frame}

\begin{frame}[fragile]{Índice positivo único}
\phantomsection\label{uxedndice-positivo-uxfanico}
Para recuperar el valor exacto de una observación, indicamos su
posición.

\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\# Extraer el peso del tercer pez evaluado}
\NormalTok{pesos\_cachama[}\DecValTok{3}\NormalTok{] }
\end{Highlighting}
\end{Shaded}

\begin{verbatim}
[1] 440.8
\end{verbatim}
\end{frame}

\begin{frame}[fragile]{Vectores de índices}
\phantomsection\label{vectores-de-uxedndices}
Podemos pasar un vector de enteros dentro de los corchetes para extraer
varios elementos al mismo tiempo, ya sea de forma continua (secuencias)
o saltada.

\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\# Extraer los primeros tres pesos (usando el operador de secuencia :)}
\NormalTok{pesos\_cachama[}\DecValTok{1}\SpecialCharTok{:}\DecValTok{3}\NormalTok{]}
\end{Highlighting}
\end{Shaded}

\begin{verbatim}
[1] 450.2 465.1 440.8
\end{verbatim}

\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\# Extraer el primer y el quinto peso específicamente}
\NormalTok{pesos\_cachama[}\FunctionTok{c}\NormalTok{(}\DecValTok{1}\NormalTok{, }\DecValTok{5}\NormalTok{)]}
\end{Highlighting}
\end{Shaded}

\begin{verbatim}
[1] 450.2 455.0
\end{verbatim}
\end{frame}

\begin{frame}[fragile]{Índices negativos}
\phantomsection\label{uxedndices-negativos}
\begin{itemize}
\item
  En R, si colocamos un signo menos \texttt{-} antes del índice, le
  estamos indicando al programa que devuelva todos los elementos del
  vector excepto ese.
\item
  Es extremadamente útil para eliminar datos atípicos o errores de
  medición sin destruir el vector original.
\end{itemize}

\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\# Mostrar todos los pesos excepto el segundo}
\NormalTok{pesos\_cachama[}\SpecialCharTok{{-}}\DecValTok{2}\NormalTok{]}
\end{Highlighting}
\end{Shaded}

\begin{verbatim}
[1] 450.2 440.8 480.5 455.0 470.3
\end{verbatim}

\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\# Excluir los últimos dos pesos usando un vector de negativos}
\NormalTok{pesos\_cachama[}\SpecialCharTok{{-}}\FunctionTok{c}\NormalTok{(}\DecValTok{5}\NormalTok{, }\DecValTok{6}\NormalTok{)]}
\end{Highlighting}
\end{Shaded}

\begin{verbatim}
[1] 450.2 465.1 440.8 480.5
\end{verbatim}
\end{frame}

\begin{frame}{Indexación por Nombres}
\phantomsection\label{indexaciuxf3n-por-nombres}
\end{frame}

\begin{frame}[fragile]{Etiquetas}
\phantomsection\label{etiquetas}
Los vectores en R pueden tener ``etiquetas'' o nombres asociados a cada
posición. En lugar de recordar el número de la posición, podemos llamar
al dato por su nombre.

\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\# Definimos el rendimiento en un examen para 4 estudiantes}
\NormalTok{notas }\OtherTok{\textless{}{-}} \FunctionTok{c}\NormalTok{(}\AttributeTok{Juan =} \FloatTok{4.2}\NormalTok{, }\AttributeTok{Ana =} \FloatTok{4.8}\NormalTok{, }\AttributeTok{Luis =} \FloatTok{3.5}\NormalTok{, }\AttributeTok{Maria =} \FloatTok{4.0}\NormalTok{)}

\CommentTok{\# Extraer la nota de Ana usando su nombre (entre comillas)}
\NormalTok{notas[}\StringTok{"Ana"}\NormalTok{]}
\end{Highlighting}
\end{Shaded}

\begin{verbatim}
Ana 
4.8 
\end{verbatim}

\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\# Extraer notas de varios estudiantes}
\NormalTok{notas[}\FunctionTok{c}\NormalTok{(}\StringTok{"Juan"}\NormalTok{, }\StringTok{"Maria"}\NormalTok{)]}
\end{Highlighting}
\end{Shaded}

\begin{verbatim}
 Juan Maria 
  4.2   4.0 
\end{verbatim}
\end{frame}

\section{Edición de elementos de un
vector}\label{ediciuxf3n-de-elementos-de-un-vector}

\begin{frame}[fragile]{Edición de Elementos mediante el Índice}
\phantomsection\label{ediciuxf3n-de-elementos-mediante-el-uxedndice}
El índice no solo sirve para ``mirar'' lo que hay en una posición, sino
también para sobrescribirlo. Se utiliza el índice del lado izquierdo del
operador de asignación \texttt{\textless{}-}

\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\# Supongamos que hubo un error de transcripción en la primera nota}
\NormalTok{notas[}\StringTok{"Juan"}\NormalTok{] }\OtherTok{\textless{}{-}} \FloatTok{4.5}
\NormalTok{notas}
\end{Highlighting}
\end{Shaded}

\begin{verbatim}
 Juan   Ana  Luis Maria 
  4.5   4.8   3.5   4.0 
\end{verbatim}

\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\# Podemos modificar varios a la vez}
\CommentTok{\# Sumar 0.2 a los estudiantes en las posiciones 3 y 4}
\NormalTok{notas[}\DecValTok{3}\SpecialCharTok{:}\DecValTok{4}\NormalTok{] }\OtherTok{\textless{}{-}}\NormalTok{ notas[}\DecValTok{3}\SpecialCharTok{:}\DecValTok{4}\NormalTok{] }\SpecialCharTok{+} \FloatTok{0.2}
\NormalTok{notas}
\end{Highlighting}
\end{Shaded}

\begin{verbatim}
 Juan   Ana  Luis Maria 
  4.5   4.8   3.7   4.2 
\end{verbatim}
\end{frame}

\section{Aplicación}\label{aplicaciuxf3n}

\begin{frame}{Aplicación Práctica: Control de Calidad de Datos}
\phantomsection\label{aplicaciuxf3n-pruxe1ctica-control-de-calidad-de-datos}
En el análisis estadístico real, la indexación es nuestra primera
herramienta de limpieza. Supongamos que tenemos un registro diario de
concentraciones de material particulado (PM10) de una estación de
calidad del aire.

Sabemos que el equipo falló el día 4, registrando un valor imposible
(-999), y queremos corregirlo antes de calcular los perfiles diarios de
contaminación.
\end{frame}

\begin{frame}[fragile]{}
\phantomsection\label{section-1}
\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\# Registros diarios de PM10 (microgramos por metro cúbico)}
\NormalTok{pm10\_diario }\OtherTok{\textless{}{-}} \FunctionTok{c}\NormalTok{(}\FloatTok{45.2}\NormalTok{, }\FloatTok{50.1}\NormalTok{, }\FloatTok{48.3}\NormalTok{, }\SpecialCharTok{{-}}\FloatTok{999.0}\NormalTok{, }\FloatTok{52.4}\NormalTok{, }\FloatTok{49.8}\NormalTok{, }\FloatTok{51.0}\NormalTok{)}

\CommentTok{\# 1. Identificamos el valor de la anomalía (posición 4)}
\CommentTok{\# 2. Usamos el índice para reemplazar el error con NA (dato faltante)}
\NormalTok{pm10\_diario[}\DecValTok{4}\NormalTok{] }\OtherTok{\textless{}{-}} \ConstantTok{NA}
\end{Highlighting}
\end{Shaded}
\end{frame}

\begin{frame}[fragile]{}
\phantomsection\label{section-2}

\begin{frame}[fragile]{Comparación de números no enteros (reales o
floats)}
\phantomsection\label{comparaciuxf3n-de-nuxfameros-no-enteros-reales-o-floats}
Comparar no enteros usando \texttt{==} es problemático. Todos los
números que hemos tratado hasta ahora son números de punto flotante
(\texttt{float}). Eso significa que se almacenan en la forma
\(a\times 2 ^ b\), para dos números \(a\) y \(b\). Dado que todo este
formato debe almacenarse en 32 bits, el número resultante es solo una
aproximación de lo que realmente se desea. Esto significa que los
errores de redondeo a menudo se introducen en los cálculos y las
respuestas esperadas pueden ser incorrectas.
\end{frame}

\begin{frame}[fragile]{Números epeciales}
\phantomsection\label{nuxfameros-epeciales}
Para ayudar con la aritmética, R admite cuatro valores numéricos
especiales: \texttt{Inf}, \texttt{-Inf}, \texttt{NaN} y \texttt{NA}

\begin{itemize}
\item
  \texttt{Inf} infinito positivo
\item
  \texttt{-Inf} infinito negativo
\item
  \texttt{NaN} es la abreviatura de {Not-a-Number} ``no es un número'' y
  significa que nuestro cálculo no tenía sentido matemático o no se pudo
  realizar correctamente
\item
  \texttt{NA} es la abreviatura de {Not Available} ``\textbf{no
  disponible}'' y representa un valor perdido, un problema demasiado
  común en el análisis de datos.
\end{itemize}
\end{frame}

\begin{frame}[fragile]{Valores lógicos}
\phantomsection\label{valores-luxf3gicos}
Además de los números, el cálculo científico a menudo involucra valores
lógicos, particularmente como resultado del uso de operadores
relacionales (\texttt{\textless{}},\texttt{\textgreater{}},\texttt{==},
etc.). Muchos lenguajes de programación usan lógica booleana, donde los
valores pueden ser VERDADEROS o FALSOS. En R, la situación es un poco
más complicada, ya que también podemos tener valores perdidos, NA.
\end{frame}

\begin{frame}[fragile]{Valores lógicos (cont)}
\phantomsection\label{valores-luxf3gicos-cont}
\texttt{TRUE} y \texttt{FALSE} son palabras reservadas en R: no puede
crear una variable con ninguno de esos nombres (aunque las versiones en
minúsculas o en mayúsculas y minúsculas como True están bien). Cuando
inicia R, las variables T y F ya están definidas para usted, tomando los
valores \texttt{TRUE} y \texttt{FALSE}, respectivamente. Esto puede
ahorrarle un poco de escritura, pero también puede causar grandes
problemas. \texttt{T} y \texttt{F} no son palabras reservadas, por lo
que los usuarios pueden redefinirlas.
\end{frame}

\begin{frame}[fragile]{Valores lógicos (cont)}
\phantomsection\label{valores-luxf3gicos-cont-1}
Esto significa que está bien usar los nombres abreviados si está
trabajando en la línea de comando, pero no si su código va a interactuar
con el de otra persona

\begin{itemize}
\tightlist
\item
  \texttt{!} se usa para la negación \texttt{no} (\texttt{not})\\
\item
  \texttt{\&} se usa para la conjunción \texttt{y} (\texttt{and}).
\item
  \texttt{\textbar{}} se usa para la disyunción \texttt{o}
  (\texttt{or}).
\end{itemize}
