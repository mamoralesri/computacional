\section{Matrices}\label{matrices}

\begin{frame}{Objetivos}
\phantomsection\label{objetivos}
Después de estudiar este capítulo, usted debería:

\begin{itemize}
\item
  Ser capaz de crear y manipular matrices.
\item
  Realizar operaciones con matrices.
\end{itemize}
\end{frame}

\begin{frame}[fragile]{Matrices}
\phantomsection\label{matrices-1}
\begin{tcolorbox}[enhanced jigsaw, breakable, arc=.35mm, title=\textcolor{quarto-callout-note-color}{\faInfo}\hspace{0.5em}{Nota}, coltitle=black, colbacktitle=quarto-callout-note-color!10!white, bottomtitle=1mm, leftrule=.75mm, left=2mm, titlerule=0mm, colback=white, toptitle=1mm, opacitybacktitle=0.6, rightrule=.15mm, opacityback=0, bottomrule=.15mm, toprule=.15mm, colframe=quarto-callout-note-color-frame]

En un sentido estricto, las matrices son arreglos de dos dimensiones, un
\texttt{largo} y un \texttt{alto}. Las matrices son, por lo tanto, una
estructura con forma rectangular, con filas y columnas.

\end{tcolorbox}
\end{frame}

\begin{frame}{Solución de sistemas lineales con infinitas soluciones}
\phantomsection\label{soluciuxf3n-de-sistemas-lineales-con-infinitas-soluciones}
Una solución al sistema \(Ax=b\) cuando el sistema tiene infinitas
soluciones, es \[x=GA\] donde \(G\) es una inversa generalizada de
\(A\).
\end{frame}

\begin{frame}[fragile]{Algoritmo para cálculo de una inversa
generalizada de A}
\phantomsection\label{algoritmo-para-cuxe1lculo-de-una-inversa-generalizada-de-a}
Para hallar una inversa generalizada de una matriz \({A}\) siga los
siguientes pasos

\begin{itemize}
\tightlist
\item
  Determine el rango de \(A\), digamos que es \(r\).
\item
  En \({A}\) halle un menor no singular de orden \(r\), llame a éste
  \({M}\).
\item
  Invierta \({M}\) y transponga la inversa: \(\left( {M}^{-1}\right)'\).
\item
  En \({A}\) reemplace cada elemento de \({M}\) por el correspondiente
  elemento de \(\left( {M}^{-1}\right)'\). Reemplace todos los otros
  elementos de \({A}\) por cero. Transponga la matriz resultante. El
  resultado es \({A}^{-}\), una inversa generalizada de \({A}\).
\end{itemize}
