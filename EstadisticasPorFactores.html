Cálculo de estadísticas por niveles de factores

Introducción

Un problema muy común al trabajar con datos es cómo calcular estadísticas de resumen y en general aplicar funciones sobre una variable pero considerando los niveles de otra u otras variables categóricas o factores. Otra forma de decirlo es hacer cálculos desagregados por niveles de uno o varios factores.

Introducción II

Para esa tarea contamos con varias funciones, que hacen la misma tarea y se diferencian solo por el formato en que entregan la respuesta, ellas son:

  • by
  • tapply
  • aggregate

Data para los ejemplos

Ejecute el siguiente código que crea un data.frame llamado puntajes que contiene nombres de jugadores de vídeo juegos y sus puntajes.

Código 
# para general siempre los mismos datos
set.seed(1234) 
# los datos 
puntaje<-data.frame(
jugador = rep(c("Tom", "Dick", "Harry"), 
          times = c(2, 5, 3)),
          puntos = round(rlnorm(10, 8), -1))

Los datos

   jugador puntos
1      Tom    890
2      Tom   3930
3     Dick   8820
4     Dick    290
5     Dick   4580
6     Dick   4940
7     Dick   1680
8    Harry   1730
9    Harry   1700
10   Harry   1220

  • Una tarea frecuente es, por ejemplo, sumar los puntos de cada jugador.

  • Lo cual podríamos hacer de la siguiente manera

Suma de los puntajes de Dick

Código 
sum(puntaje[puntaje$jugador=="Dick",2])
[1] 20310

  • La forma anterior funciona, pero sería poco eficiente, cuando se tengan muchos jugadores, porque habría que ejecutar el código para cada jugador.

  • Ilustraremos varias formas de hacer esta tarea.

  • La diferencia está en el formato en que se obtiene la respuesta.

Uso de by

Con by

Código 
with(puntaje, by(puntos, jugador, sum))
jugador: Dick
[1] 20310
------------------------------------------------------------ 
jugador: Harry
[1] 4650
------------------------------------------------------------ 
jugador: Tom
[1] 4820

Guardamos la repuesta en un objeto

Código 
sumas=with(puntaje, by(puntos, jugador, sum))

Acceso a los resultados de by

El objeto sumas creado por el código anterior, es de clase by, pero se puede acceder a sus elementos como una lista

Código 
class(sumas)
[1] "by"
Código 
names(sumas)
[1] "Dick"  "Harry" "Tom"
Código 
sumas[["Dick"]]
[1] 20310
Código 
sumas[["Harry"]]
[1] 4650

Código 
is.list(sumas)
[1] FALSE

Uso de tapply

Cálculos con tapply

La función tapply regresa un vector o una tabla

Código 
with(puntaje,tapply(puntos, jugador, sum))
 Dick Harry   Tom 
20310  4650  4820

Note que la respuesta es la misma, solo que está en un formato distinto (array).

Código 
sumas=with(puntaje, tapply(puntos, jugador, sum))
class(sumas)
[1] "array"
Código 
names(sumas)
[1] "Dick"  "Harry" "Tom"

Uso de aggregate

Con aggregate

Note que en este caso la variable que clasifica se debe entregar como una lista list(jugador)

Código 
with(puntaje,aggregate(puntos, list(jugador), sum))
  Group.1     x
1    Dick 20310
2   Harry  4650
3     Tom  4820

La función aggregate regresa la respuesta como un data.frame

Código 
sumas=with(puntaje,aggregate(puntos, list(jugador), sum))
class(sumas)
[1] "data.frame"

Ejemplos

Ejemplo 2

Considere el siguiente conjunto de datos simulados. Calcule el ritmo cardíaco promedio discriminado por Sexo y Edad

Código 
set.seed(231)
n<-sample(seq(50,300,by=5),1)
Edad<-round(rnorm(n,mean=20,sd=0.5))
Peso<-round(rnorm(n,mean=60,sd=3))
Sexo<-sample(c("F","M"),n,replace=TRUE)
Hijos<-rpois(n,lambda=2)
Estrato<-sample(1:6,n,replace = TRUE, prob = c(0.30,0.20,0.15,0.15,0.13,0.07) ) 
Ritmo<-round(rnorm(n,mean=60,sd=0.75)) 
Datos<-data.frame(Edad,Peso,Sexo,Hijos,Estrato,Ritmo)

Los datos

Código 
tail(Datos) 
   Edad Peso Sexo Hijos Estrato Ritmo
75   20   56    M     1       1    59
76   21   68    F     3       3    61
77   19   58    F     1       1    61
78   20   63    M     3       4    60
79   20   60    F     1       2    60
80   20   63    F     2       5    60

En este ejemplo Datos tiene 80 filas.

Solución con tapply

Note el uso de list para entregar los factores que clasifican

Código 
with(Datos, tapply(Ritmo, list(Sexo, Edad), mean))
        19       20 21
F 60.75000 60.25926 60
M 60.16667 59.81818 60

Note que la respuesta se entrega como una matriz

Solución con aggregate

Código 
with(Datos, aggregate(Ritmo, list(Sexo, Edad), mean)) 
  Group.1 Group.2        x
1       F      19 60.75000
2       M      19 60.16667
3       F      20 60.25926
4       M      20 59.81818
5       F      21 60.00000
6       M      21 60.00000

La función aggregate regresa la respuesta como un data.frame
