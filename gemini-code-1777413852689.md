## ¿Qué es Quarto?

Es el sistema de publicación científica de última generación. Permite combinar:

* **Texto narrativo** (Markdown).
* **Código de programación** (R o Python).
* **Resultados matemáticos** (LaTeX).

Todo en un solo documento **reproducible**.

## El Flujo de Trabajo

1.  **Escribes:** Creas tu archivo `.qmd`.
2.  **Renderizas:** Presionas el botón **Render** (el martillo azul ).
3.  **Publicas:** Obtienes un PDF, HTML o Word profesional.

> **Regla de Oro:** Lo que ves en el código es lo que obtienes en el informe.

## Markdown: El Lenguaje Simple

Es texto plano que Quarto transforma en diseño profesional:

* `# Título` se convierte en un encabezado principal.
* `**Negrita**` resalta conceptos clave.
* `*Cursiva*` para énfasis.
* `- Listas` para organizar ideas.

## Adiós al "Copia y Pega"

En estadística, los datos cambian. Con Quarto:

* Si actualizas tu base de datos, el informe **se actualiza solo**.
* Los gráficos de `ggplot2` se insertan automáticamente.
* No hay riesgo de transcribir mal un p-valor o una media.

## El Idioma de Gauss (LaTeX)

Para sus fórmulas, usen la sintaxis universal:

$$\bar{x} = \frac{1}{n} \sum_{i=1}^{n} x_i$$

Se escribe así de fácil: 
`$$\bar{x} = \frac{1}{n} \sum_{i=1}^{n} x_i$$`
